# Khayubdi UI Guide

## Visual Direction

Khayubdi uses a premium fitness-tech style: black base, neon green highlights, high-contrast cards, and compact mobile-first layouts.

## Colors

- App background: near-black
- Primary surface: dark charcoal
- Secondary surface: dark gray
- Primary accent: neon green
- Success: neon green
- Warning: amber/yellow
- Danger: red
- Muted text: gray
- Primary text: white or very light gray

Suggested tokens:

- `--bg`: `#050806`
- `--surface`: `#101510`
- `--surface-2`: `#161d17`
- `--accent`: `#35ff7a`
- `--accent-soft`: `rgba(53, 255, 122, 0.16)`
- `--text`: `#f4fff7`
- `--muted`: `#93a196`

## Typography

- Use clean sans-serif fonts.
- Use strong headings for page titles.
- Keep dashboard labels short and scannable.
- Thai user-facing labels should be direct and simple.
- Avoid oversized hero text inside dashboard cards.

## Buttons

- Primary buttons use neon green emphasis.
- Secondary buttons use dark surface with green border or soft accent.
- Destructive actions should use confirmation before deleting data.
- Buttons must be large enough for thumb tapping on mobile.

## Cards

- Use cards for individual content groups such as summary, food meal groups, check-in history, and profile sections.
- Keep card radius moderate and consistent.
- Avoid nesting cards inside cards.
- Use strong labels and numeric values for tracking data.

## Spacing

- Mobile screens should use generous outer padding.
- Repeated cards should have consistent vertical spacing.
- Form controls should be grouped by task.
- Avoid cramped tap targets.

## Icons

- Current MVP uses text and simple symbols.
- Future icon use should be functional, not decorative.
- Icons should clarify actions such as save, delete, add, camera, and progress.

## Navigation

Primary mobile tabs:

- Dashboard
- Check-in
- Food
- Workout
- Progress
- Profile

Inactive or future pages should show clean empty states rather than broken UI.
